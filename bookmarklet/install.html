TypeThru bookmarklet

Types text into the vSphere HTML5 web console without installing an extension.

Install

Show the favorites bar (Ctrl+Shift+B) and drag the button that matches the guest's keyboard layout onto it:

Or create a favorite manually and paste one of these as the URL:

German guest layout (DE → US conversion):

US guest layout (no conversion):

Use

  1. Open the VM with Launch Web Console and click once into the console.
  2. Click the bookmarklet in the favorites bar.
  3. Enter the text in the dialog and press OK.
  4. Click back into the console.

Notes

  • The browser dialog shows the text in clear text while you type.
  • With DE → US conversion these characters are refused instead of being typed wrong: @ € { [ ] } \ ~ | < > µ ² ³
  • Nothing is stored or sent anywhere; the text only goes to the console on the current page.
