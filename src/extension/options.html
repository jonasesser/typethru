Allowed vCenter hosts

TypeThru only sends text to web consoles on these hosts. One host per line, for example vcenter.example.com or *.example.com for all subdomains.

Leave empty to allow every host. The popup always shows the target before sending.

This list is set by your organization and cannot be changed here.
