# TypeThru privacy policy

Last updated: 2026-10-26

TypeThru is a browser extension that types text into the vSphere HTML5 web console.
This policy explains what happens with the information you enter.

## Summary

TypeThru does not collect, store, sell or share personal data. It makes no network
requests and contains no analytics or tracking.

## Text you enter

- The text you type into the TypeThru popup (for example a password or a command) is
  passed only to the web console on the tab you are currently using.
- The text is not saved, not logged and not sent to the developer or any third party.
- After sending, the input field is cleared and the popup closes.

## Settings

TypeThru remembers the guest keyboard layout you selected. This setting is stored
locally in your browser and never leaves your device.

## Permissions

- **activeTab** – access to the current tab only after you click the TypeThru icon or
  press its shortcut.
- **scripting** – to find the web console on that tab and pass your text to it.

TypeThru has no permission to access other websites or tabs.

## Third parties

TypeThru does not use third-party services. The web page you send text to (your
vCenter) receives the text, just as if you had typed it yourself.

## Changes

Changes to this policy are published in this file in the project repository.
